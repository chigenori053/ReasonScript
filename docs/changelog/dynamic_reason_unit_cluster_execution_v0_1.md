# Dynamic ReasonUnit Cluster Execution v0.1

Added the optional Rust dynamic ReasonUnit runtime, thin `reason cluster dynamic` adapter, nine JSON contracts, canonical lifecycle and proposal processing, atomic plan revisions, bounded branch management, convergence reporting, artifact generation and replay validation, thirteen acceptance scenarios, and a molecular dynamic scenario.

Compatibility: no ReasonScript grammar, Reason IR, ExecutionPlan, single-node runtime, or static Cluster Runtime behavior was changed.
