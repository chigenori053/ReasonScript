# RUO-T1 Tensor Representation

- Added the versioned `ruo.payload.tensor/1` / `ruo.tensor/1.0` profile.
- Added canonical codecs for all 15 core dtypes and strict finite/positive-zero validation.
- Added dense row-major, sparse COO/CSR, inline, `.ruot`, chunk, mask, mapping, digest, selector, converter, and atomic publication contracts.
- Added the `reason reasonunit-tensor` offline CLI and 47 canonical phase artifacts.
- Preserved RUO-U1 identity semantics, RUO-F1 record encoding, and existing Tensor Runtime behavior.
