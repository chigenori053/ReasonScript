# ReasonScript Reasoning Evaluation Report v1.0

## Status

VALIDATED FOR PHASE 8B

## Version

`reasonscript-reasoning-evaluation-report/1.0`

## Purpose

ReasoningEvaluationReport is the versioned artifact generated by evaluating a
Phase 8A ReasoningModel artifact. It reports whether required checks pass for
the model's EvaluationTarget.

## Scope

Phase 8B defines the report contract, deterministic serialization, report
validation, evaluator behavior, CLI wiring, and CI compatibility target.

Phase 8B does not introduce new source syntax, parser behavior, runtime
execution behavior, Reason IR execution behavior, or model training behavior.

## Required Top-Level Fields

- `schema_version`
- `report_id`
- `model_ref`
- `evaluation_target_ref`
- `summary`
- `checks`
- `diagnostics`

## Required Checks

- `reachability`
- `determinism`
- `evidence_completeness`
- `consistency`
- `minimality`
- `branch_traceability`

## CLI

```sh
reason reasoning-eval evaluate <reasoning-model.json> --json
reason reasoning-eval validate <evaluation-report.json> --json
```

## Completion Criteria

Phase 8B is complete when the contract, schema, evaluator, validator, CLI,
fixtures, tests, changelog, and CI compatibility target exist and required
validation passes through the canonical `reason ci` entry point.
