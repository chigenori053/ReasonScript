# ReasonScript v0.5.4.2 Release Definition

Specification ID: `reasonscript-release/0.5.4.2`
Status: IN_PROGRESS
Date: 2026-07-28

ReasonScript 0.5.4.2 introduces the Semantic Visualization Runtime v0.1
Milestone 1. The canonical version is `0.5.4.2` across `VERSION`, Python
package metadata, release metadata, runtime metadata, and the validation
profile. Runtime compatibility remains `>=0.5.0,<0.6.0`.

The package must include `VisualizationRuntime`, `reason-visualization`, the
person-structure fixture, and the `reason visualization` CLI. It must pass
source-tree CI, update-package validation, staged native validation, local
update installation, and installed visualization generation/validation.
